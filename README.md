# KAYOSI Trading CC — Website

Responsive static website package for KAYOSI Trading CC, Ballito, KwaZulu-Natal.

## Website content
- Original KAYOSI Trading logo (`assets/kayosi-full-logo.jpg`).
- Navy, blue, gold, white and grey brand system.
- Homepage, company overview, services, logistics, PPE, corporate branding, procurement, supplier brands and contact sections.
- Ten separate, locally stored illustrative PPE images, one for each category.
- Supplier brand section includes Amrod, Jonsson Workwear, BOVA, AECI and Lasher.
- Contact details and an enquiry form that prepares an email for the visitor.

## Accuracy and presentation
The ten PPE images are illustrative product visuals, not manufacturer photographs, product-SKU evidence or proof of stock. The welding image is reserved for Specialist PPE; the other nine category images each depict their named PPE type. Exact brand, model, specification, applicable standards, size, price and availability must be confirmed with each quotation.

AECI's product range includes industrial chemicals and products serving construction and infrastructure. Lasher's catalogue includes hand tools such as spades, shovels and wheelbarrows. Website copy presents these as product ranges KAYOSI can assist customers to source; it does not claim exclusive distribution or formal appointment.

Supplier logos and trademarks remain the property of their respective owners. The supplier section does not claim exclusive or formally appointed partnerships.

## Image hosting
The ten PPE category images, KAYOSI logo and favicon are stored locally in `assets/`. Some decorative section backgrounds and third-party supplier/product images are still loaded from external websites; those external hosts can change or block image delivery. If an external image stops loading, the page content and locally stored PPE category images remain available. For long-term production use, use approved local copies of third-party brand assets where permission is available.

## Publish to GitHub Pages
1. Extract this ZIP.
2. Upload the contents of the `kayosi-complete` folder (not the outer folder) into the root of your chosen repository.
3. Confirm that `index.html`, `styles.css`, `script.js`, `README.md` and `robots.txt` are at the repository root, alongside the `assets` folder.
4. In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/ (root)**.
5. Use the **Visit site** link shown in Settings → Pages to open the exact published address. A project-site URL includes the repository name after `https://zeusthepoes.github.io/`.
6. GitHub says publishing can take up to 10 minutes after a push. If it remains unavailable, check the latest Pages deployment result.

The `.nojekyll` file is included at the repository root to disable Jekyll processing for this plain static site.
